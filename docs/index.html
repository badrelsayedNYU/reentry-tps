Numerical convergence table · Automated validation checks

Model: planar point-mass trajectory over a spherical, non-rotating Earth with an exponential atmosphere (ρ₀ = 1.225 kg/m³, H = 7.2 km), integrated from 120 km to 500 m/s. Sutton–Graves stagnation heating (cold-wall by default, optional hot-wall correction) with surface re-radiation (ε = 0.85). Implicit finite-volume conduction with temperature-dependent properties from NASA RP-1289, adiabatic back face, soak-back until the bondline peaks. Valid for non-ablating tiles below about 10 km/s; stagnation point only. This page is a JavaScript port of the Python model and reproduces its baseline (7.03 cm of LI-900, 43.7 W/cm², 129 MJ/m², bondline peak at 3464 s) and its parameter sweeps. Built by Badr Elsayed.
